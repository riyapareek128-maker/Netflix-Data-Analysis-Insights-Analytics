# 🎬 Netflix Data Analysis & Insights Analytics

## 📊 Project Overview

Netflix Data Analysis & Insights Analytics is a SQL-based analytics project designed to evaluate streaming data across Netflix's content library.

The project uses datasets covering movies, TV shows, genres, directors, ratings, and release years. SQL is used to analyze content distribution, duration patterns, release trends, top producing countries, and genre popularity.

The primary objective of this project is to demonstrate how SQL can transform raw media data into meaningful insights that support data-driven analysis and business decision-making.

## 🎯 Project Objectives

The project focuses on analyzing:

* 👥 Content & Format Distribution (Movies vs TV Shows)
* ⏱️ Content Duration & Genre Trends
* 🌍 Geographic & Country-wise Production
* 📈 Yearly Content Addition Patterns

## 🛠️ Tech Stack & Tools

* 🗄️ **Database:** MySQL / PostgreSQL
* 💻 **Language:** SQL (Data Filtering, Aggregations, CTEs, Window Functions)
* 📁 **Dataset:** Netflix Movies and TV Shows Data (`data-1764043566469.csv`, `NetflixUTF.csv`)
